DSA PIPELINE

How LyricMatch Works

The system combines multiple Data Structures and Algorithms to analyze and compare lyrics.

01

Text Processing

The entered lyrics are cleaned, converted to lowercase, and divided into individual words for analysis.

Text Processing
02

Jaccard Similarity

The system compares the unique words in the query with the words in each stored song and calculates a similarity score.

Set Analysis
03

Merge Sort

The calculated similarity scores are sorted from highest to lowest so the closest matching songs appear first.

Sorting
04

KMP Pattern Matching

The Knuth-Morris-Pratt algorithm searches for matching phrases efficiently inside the stored lyrics.

Pattern Matching
05

Final Analysis

The system combines the similarity ranking and matching passages and displays the analysis to the user.

Result
